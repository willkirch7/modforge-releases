# ModForge

Mix your games: take a character, weapon, monster or soundtrack from one game and drop it into another.

**Download:** grab `ModForge-Setup-<version>.exe` from the [latest release](https://github.com/willkirch7/modforge-releases/releases/latest).

Windows 10/11. Installed copies update themselves.

The first time you run it, Windows may say "Windows protected your PC". Click **More info**, then **Run anyway**.
